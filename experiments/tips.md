# 実験から選ぶ、残り2つの Tips

subagent、実行ループ、コスト以外の候補として、2026-11-25 の Framekit #796 調査から以下を選ぶ。どちらも少数例に基づく実践上の助言で、Fusion の保証や一般的な優劣ではない。

## 1. 回答に根拠を求め、重要な説明を元のコードで確かめる

**観測:** [High と Max の比較](effort-quality-observation.md)では両者が hero の場所と opacity 0 の開始を挙げた。一方、Max の回答は「600ms と遅延の間ずっと不可視」と説明した。実際の `EnglishOverview.module.scss` は opacity 0 から 1 へのアニメーションであり、遅延後は徐々に表示される。提案されたテストも実行していない。

**使い方:** パスと行、何を確認したか、未実行のテストを回答に含めるよう依頼し、判断に影響する主張は固定したソースや実行結果と照合する。もっともらしい詳細やテスト案を、そのまま測定結果として発表しない。

**限界:** 誤りはこの1回答での観測であり、Max 全般の品質評価ではない。外部 Issue を読めない条件でのコード調査であり、実ブラウザの受け入れ検証は未実施。

## 2. 必要な要件を渡し、読めなかった情報を確認する

**観測:** 外部アクセスを禁止して Issue 番号だけを渡した先行 High / Max の回答は、本文を読めなかったと明示した。追試では同じ固定 SHA の独立 checkout、外部アクセス禁止・`task` 禁止の High に公開 Issue #796 の本文を添付した。回答は Issue の 4.5:1、両 CTA、図の文字、light/dark、初期から3秒を含む2つのテスト案を示し、未実行と明記した。事前の品質基準と結果は [追試の記録](effort-quality-observation.md#レビュー後-品質基準付きの-high-優先戦略)を参照。

**使い方:** 外部アクセスを許可しないときは、共有可能な課題本文と受け入れ条件を依頼に含める。結果を元の要件と照合し、対象・閾値・実行済みかどうかを確認する。

**限界:** 本文を与えた今回の High は GPT-6 Astra に、先行の本文なし High は GPT-6.1 Terra にルーティングされた。時刻、キャッシュ、checkout も異なるため、品質の違いを本文の有無だけの効果とは言えない。テスト案は実行しておらず、1課題での観測である。共有する文章に機密がないか確認する。
